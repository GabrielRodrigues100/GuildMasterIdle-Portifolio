# Guild Master Idle - Portifolio

Jogo desenvolvido na Godot Engine como projeto pessoal.

## Sobre

Este projeto é um jogo **Idle** desenvolvido para dispositivos **Android** utilizando a **Godot 4**. O objetivo do jogador é administrar uma guilda de aventureiros, recrutando novos membros, enviando-os para missões e gerenciando os recursos obtidos para expandir e fortalecer a guilda.

Ao longo da progressão, o jogador pode recrutar aventureiros, enviá-los para diferentes missões a fim de coletar recursos e utilizar esses recursos para construir e aprimorar os edifícios da guilda, desbloqueando novas possibilidades de evolução.

## Tecnologias

* Godot 4.x
* GDScript
* Git / GitHub

## Funcionalidades

* Interface (HUD e menus).
* Recrutamento de aventureiros.
* Sistema de missões Idle.
* Gerenciamento de recursos.
* Construção e melhoria de edifícios.
* Sistema de salvamento.

## Aprendizados

Neste projeto pratiquei organização de cenas, GDScript, gerenciamento de estados e controle de versão com Git.

## Status do projeto

O jogo está em fase final de desenvolvimento. A publicação na Google Play está em andamento e a versão jogável será disponibilizada após a aprovação da conta no Google Play Console.
